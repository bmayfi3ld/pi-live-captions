# Contributing

## AI Usage

First to call out the obvious, the individual lines of code in this project are written by AI coding agents. This section (one of the few things written by a human) aims to document how AI is to be used.

Only use the latest frontier models using standard spec driven development practices and high reasoning effort. The quality difference between this and yolo'ing code out with a cheap model is often staggering. You still need to actually review all of your code before submitting it, and understand the architecture of it. This project is not totally vibe coded, the general software architecture is managed by humans (things like package layout and responsibility, interfaces between packages, data structures). Think of yourself as a tech lead with an intern (only one), you can not reasonably accept their code without reviewing it yourself. But at the same time you do not review every last if statement (even to try and catch off by one errors).

And last and probably most important, only submit reasonably sized MRs, I will still be reviewing them myself and do not want crazy overbuilt vibed out features.
